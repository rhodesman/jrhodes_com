## Project Overview

Personal portfolio website for Jason Rhodes (Sr. Web Developer, Development Team Lead & Frontend Engineer). It's a **Vite + React 19 + TypeScript** single-page app in `client/`, built to `site/dist/` and served by a thin **Express 5** server (`app.js`).

## Commands

- **Development:** `npm run dev` — runs the Vite dev server and the Express server concurrently (`concurrently` labels them `client`/`server`).
- **Build:** `npm run build` — `vite build` compiles `client/` → `site/dist/`.
- **Typecheck:** `npm run typecheck` — `tsc --noEmit` against `client/tsconfig.json`.
- **Production start:** `npm start` — builds, then runs the Express server on port 8888.
- **Serve only (no build):** `npm run serve` — `node app.js`.
- **Debug:** `npm test` — `node --inspect app.js` (this is a debugger launch, **not** a test suite — the project has no test runner).

## Architecture

- **`client/`** — the Vite + React + TypeScript source (this is where nearly all work happens):
  - `client/index.html`, `client/vite.config.ts`, `client/tsconfig.json` — Vite/TS config.
  - `client/src/main.tsx` — entry; imports FontAwesome Free CSS and mounts `<App>`.
  - `client/src/App.tsx` — composes the page sections (`Nav`, `Hero`, `About`, `Skills`, `Experience`, `Portfolio`, `Contact`).
  - `client/src/components/` — one component per section, plus games (`BlackHoleGame`, `OutRunGame`, `QuincyGame`) and helpers.
  - `client/src/styles/main.scss` (+ `inc/` partials) — styling, compiled by Vite via `sass-embedded`.
  - `client/src/lib/ansi.ts` — Jurassic Park terminal easter egg, logged to the console from `App.tsx`.
- **Portfolio cards** — the rendered card grid lives in `client/src/components/Portfolio.tsx` (its local `PROJECTS` array is the **single source of truth**). `client/src/data/projects.ts` also lists projects but is **not imported anywhere** — it has no runtime effect; update it only for consistency.
- **`app.js`** — thin Express 5 server. Serves the built SPA from `site/dist/` first, then the rest of `site/` (live-demos, images, favicon). Listens on `process.env.PORT || 8888`. Registers `controls/routes.js`.
- **`controls/routes.js`** — currently a stub reserved for future server-side endpoints (e.g. a contact form/API). There is no longer a `/fw/:name` asset-proxy route.
- **`site/`** — static root served by Express:
  - `site/dist/` — Vite build output (**gitignored**; regenerated by `npm run build`).
  - `site/live-demos/` — self-contained legacy demo projects (e.g. `curious-george`, `liberty-mutual`, `opower-pge`). Kept on disk even when not linked from the portfolio.
  - images and other static assets.

## Build & Deploy Notes

- `site/dist/` is **gitignored** — never commit build output. The build runs at deploy time (`npm start`, or `npm run build` before restarting the server).
- Styling is SCSS compiled by Vite (`sass-embedded`). FontAwesome **Free 6** and Bootstrap 5 are available as dependencies.
- **Production:** the app runs under **PM2** (`ecosystem.config.js`, process `jrhodes-com`, port 8888) on the Ubuntu server, behind nginx-proxy-manager and Cloudflare. Redeploy = `git pull && npm run build && pm2 restart jrhodes-com`.
- Design/implementation docs for larger changes live under `docs/superpowers/`.
